# Lumen — английский через чтение

Веб-приложение (PWA) для iPhone: пользователь переводит английские фразы и короткие истории уровней A1–B1 на русский, собирая перевод из плиток со словами-обманками. Долгое нажатие на слово показывает перевод и добавляет слово в раздел «Повторение» (интервальное повторение с ежедневной подборкой).

Пользователи: основной — девушка автора (учит английский, мало читала тексты), второй — автор (тестировщик, уровень английского выше). У каждого свой профиль.

## Жёсткие ограничения

- **Без сервера.** Хостинг — GitHub Pages (репозиторий `EterniteSp/english-reader`, ветка `main`, корень). Адрес: https://eternitesp.github.io/english-reader/
- **Без сборки.** Чистые HTML/CSS/ES-модули, никаких бандлеров и npm-зависимостей в рантайме. Все пути относительные (сайт живёт в подпапке `/english-reader/`).
- **Прогресс только в браузере** (`localStorage`, ключ `lumen:v1`). Есть экспорт/импорт JSON в настройках. Не ломать формат данных без миграции в `js/store.js → migrate()`.
- Интерфейс — на русском. Английский текст — шрифт Literata, интерфейс — Onest.

## Структура

```
index.html            оболочка, ранняя установка темы
manifest.webmanifest  PWA
sw.js                 офлайн: сначала сеть, при отсутствии — кэш
css/app.css           все стили, токены светлой/тёмной темы в :root
js/app.js             маршруты (#/, #/text/:id, #/text/:id/read, #/review, #/words, #/progress, #/settings) и экраны
js/store.js           состояние, профили, опыт/уровни, серии дней, экспорт/импорт, тема
js/srs.js             повторение: ежедневная подборка, интервалы, «Не знаю», подбор новых слов, варианты ответа
js/content.js         сборка текстов, разбор плиток, проверка ответа
js/lexicon.js         словарь: разбор, автоформы (-s/-ed/-ing/-er), поиск слова и выражений в контексте
js/data.js            подключение файлов словаря
js/ui.js              иконки, тосты, диалоги, озвучка (speechSynthesis)
data/dict-a1.js, dict-a2.js, dict-b1.js   словарь по уровням (~2600 слов)
data/names.js         имена и названия мест
data/phrases-*.js     тематические наборы фраз (по 12)
data/texts-*.js       связные истории (по 7–8 предложений)
tools/validate.mjs    проверка данных — запускать после любых правок контента
tools/dedupe-dict.mjs убирает повторы словаря между уровнями
docs/                 подробности: формат контента, механика, решения
```

## Команды

```bash
node tools/validate.mjs        # обязательно перед коммитом: все слова в словаре, обманки не совпадают с ответом
node tools/dedupe-dict.mjs     # после добавления слов в словарь
python3 -m http.server 8765    # локальный просмотр: http://localhost:8765/
```

## Правила для контента (важно)

- Формат и правила написания фраз — `docs/content-format.md`. Главное:
  - обманки должны быть **однозначно неверными** (другой падеж/время/смысл), а не синонимами правильного ответа;
  - предлоги с существительным и «не» с глаголом — одной плиткой;
  - избегать первого лица в прошедшем времени и в кратких прилагательных («я устал/устала») — перевод зависит от рода; использовать «мы» или третье лицо;
  - «you» → выбирать одно из «ты/вы» и не давать второе обманкой.
- Каждое английское слово должно находиться в словаре (валидатор проверяет).
- Уровень слова задаётся файлом словаря; новое слово кладётся в файл своего уровня.
