# Формат контента

## Наборы фраз и истории

Файлы `data/phrases-a1.js` … `data/texts-b1.js` экспортируют массив наборов:

```js
{
  id: 'p-a1-03',            // уникальный: p-<уровень>-NN для фраз, <уровень>-NN для историй
  title: 'Food and Drinks', // английское название
  ru: 'Еда и напитки',      // русское название
  icon: '🍎',
  s: [ /* предложения */ ],
}
```

Тип (фразы или история) определяется файлом. Уровень — тоже файлом.

### Предложение

```js
['I don\'t eat meat.', 'Я | не ем | мясо', ['ем', 'рыбу', 'ешь'], ['Мясо | я | не ем']]
//  английский          правильные плитки    обманки (2–4)     другие естественные порядки (необязательно)
```

- Плитки разделяются ` | `. Знаки препинания в плитках используются только для красивого показа правильного ответа; при сравнении и на кнопках они убираются.
- Тире: `'Моя мама — | врач'` → плитки «моя мама», «врач», а ответ показывается как «Моя мама — врач.»
- Первая плитка автоматически пишется с маленькой буквы (кроме имён из `data/names.js`), чтобы заглавная не подсказывала начало.

### Как проверяется ответ

Ответ верен, если набор плиток совпадает с правильным (порядок свободный — как в русском языке). Если порядок совпадает с основным или одним из «других порядков», показывается «Перевод: …», иначе — «Тоже правильно. Чаще говорят так: …».

### Правила хорошего предложения

1. **Обманки однозначно неверны.** Хорошо: неправильный падеж (`рыба` вместо `рыбу`), время (`любила`), лицо (`он`), другой смысл (`мясо`). Плохо: синоним правильного ответа (`кот` для «cat», `тоже` для «also»).
2. **Связки одной плиткой:** предлог + существительное (`на диване`), `не` + глагол (`не ем`), устойчивые сочетания (`идёт дождь`).
3. **Род говорящего.** Не писать «Я устала/устал», «я был/была» — у пользователей разный пол. Использовать «мы», третье лицо или настоящее время.
4. **ты/вы.** Выбрать одно, второе не давать обманкой.
5. Каждое английское слово должно быть в словаре — `node tools/validate.mjs` покажет недостающие.

## Словарь

`data/dict-a1.js`, `dict-a2.js`, `dict-b1.js`, `names.js` — строки вида:

```
слово | часть речи | перевод (варианты через запятую, первый — основной) | особые формы
go | v | идти, ехать | went, gone, goes, going
look for | ph | искать | looked for, looks for, looking for
```

- Части речи: `n v adj adv pron prep conj num det ph int name`.
- Обычные формы (-s/-es/-ies, -ed, -ing, удвоение согласной, -er/-est) строятся автоматически; неправильные — перечислить.
- Выражения из 2–4 слов (`ph`, а также существительные с пробелом вроде `ice cream`) находятся при долгом нажатии на любое их слово.
- Основной перевод (первый) используется как правильный ответ в «Повторении», поэтому он должен быть коротким.
- Одно и то же слово с разными частями речи — разные строки (`book | n` и `book | v`).
- После добавления: `node tools/dedupe-dict.mjs` и `node tools/validate.mjs`.

Текущий объём: A1 ≈ 690, A2 ≈ 885, B1 ≈ 1020 слов (всего ≈ 2600).
