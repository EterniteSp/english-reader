# Изменения

## 2026-10-16 — первая версия

- PWA на GitHub Pages: упражнения с плитками и обманками, свободный порядок слов.
- Долгое нажатие на слово: перевод и добавление в «Повторение».
- Повторение: ежедневная подборка, шкала прогресса, «Не знаю», «Подобрать новые слова», список своих слов.
- Профили, режим тестировщика, очки и уровни, звёзды, серия дней, график за 14 дней.
- Светлая/тёмная/авто тема, frosted glass, мягкие градиенты.
- Экспорт/импорт прогресса, офлайн-режим.
- Контент: 42 набора фраз (504 фразы) и 36 историй (274 предложения) уровней A1–B1.
- Словарь ≈ 2600 слов по уровням (A1 ≈ 690, A2 ≈ 885, B1 ≈ 1020).
