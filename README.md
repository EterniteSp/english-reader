# Lumen

Английский через чтение: переводите фразы и истории уровней A1–B1, собирая перевод из слов. Долгое нажатие на слово показывает перевод и добавляет его в ежедневное повторение.

**Открыть:** https://eternitesp.github.io/english-reader/

**Установить на iPhone:** открыть ссылку в Safari → «Поделиться» → «На экран „Домой“». Прогресс хранится в телефоне; копию можно сохранить в Настройки → Данные.

Документация для разработки — `CLAUDE.md` и папка `docs/`.
